# Dots Connect & Clear

一款受 *Dots & Co.* 启发的 Python 连点消除游戏，也是一个适合初学者循序渐进学习 Python、Tkinter 和面向对象设计的实践项目。

本项目参考 [UQ CSSE1001/7030 2017 S2 Assignment 3](https://csse1001.github.io/records/2017s2/a3/index.html)。由于原始支持代码已难以取得，当前版本依据任务说明与原有架构重新实现，并针对界面和玩法做了适当调整。

运行游戏：

```powershell
pip install -r origin/requirements.txt
python origin/a3.py
```
